**Payment Gateway System**

A small Python project that demonstrates how different payment methods can share a common `pay()` interface. It uses separate classes for credit card, UPI, net banking, and wallet payments, then processes each one from a list.

## Payment methods

- Credit card
- UPI
- Net banking
- Wallet

## Run the project

Open `Payment Gateway System.ipynb` in Jupyter Notebook or Google Colab and run the code cell. No additional Python packages are required.

The notebook prints a processing message for each payment method. This is a simple object-oriented programming example; it does not connect to a real payment service or process actual transactions.

## Example output

```text
Processing Credit Card Payment
Processing UPI Payment
Processing Net Banking Payment
Processing Wallet Payment
```
